# Edit without flattening the voice

Work from the supplied draft and intended audience. Ask only for missing context that materially changes the edit.

Preserve meaning, factual detail, uncertainty, vocabulary, humor and rhythm. Make the smallest effective edit; do not invent evidence or make every paragraph equally polished. Remove setup, repetition and grand claims when they add nothing, rather than banning particular words regardless of context.

Examples of useful cuts:

- Replace generic importance with the concrete consequence already supported by the draft.
- Name the source behind an attribution, or flag the unsupported claim.
- Remove a dramatic ending that only repeats the point; do not replace it with another slogan.

For an edit, return the revised draft and explain substantial changes briefly. For detection, quote the formulaic passage and suggest a concrete correction without rewriting the draft or claiming to identify AI authorship.

Use [eval.md](eval.md) for a final comparison against the original, especially when the edit substantially changes structure or length.
